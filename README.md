# Two Roads West

A family winter-break planner comparing two detailed road trips for December 18, 2026 through January 1, 2027:

- Menlo Park through Reno, Salt Lake City, and Utah’s national parks to Las Vegas
- Menlo Park through Mendocino, the redwoods, and the Oregon coast to Portland

The published site is [ibendavi.github.io](https://ibendavi.github.io/).

## Local development

```text
npm install
npm run dev
```

Build the static GitHub Pages artifact with `npm run build:pages`. Drive times and mileage are planning estimates; use the official road and park links on the site for live conditions.
